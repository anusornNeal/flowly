# Flowly Curated Skills

Each subdirectory contains an individually selectable `SKILL.md` with YAML `name` and `description`. These skills are **advisory**, not executable plugins and not an alternative to the Flowly domain API. Start with `skill-router`, or `agent-bootstrap` when the agent has no project context.

Do not load the entire directory into a prompt. Read specialist instructions only after routing and preserve exact source/version provenance when registry support is available. User-authored project skills are never automatically promoted into this trusted builtin namespace.
